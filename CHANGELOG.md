# Changelog

## 1.0.0 - 2026-11-23

Initial public release of JSONDoctor.

- JSON syntax validation with line and column information
- Pretty-print and minify
- Deep comparison and diff
- Safe diagnostics and deterministic repair
- Flatten / unflatten with escaped keys and array indices
- JSONPath-subset value extraction
- JSON Schema draft-07 validation via Ajv
- Structural statistics
- `jsondoctor` CLI with explicit write/overwrite behaviour
